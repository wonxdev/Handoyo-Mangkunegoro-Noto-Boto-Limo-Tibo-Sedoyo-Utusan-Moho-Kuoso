# Handoyo-Mangkunegoro-Noto-Boto-Limo-Tibo-Sedoyo-Utusan-Moho-Kuoso
Website landing page sederhana yang menampilkan nama dan pesan reflektif tentang identitas, tujuan, dan perjalanan.

## Visualisasi
Halaman website dapat dibuka melalui file [index.html](index.html).

## Tech Stack
- HTML5 untuk struktur halaman
- CSS3 untuk styling dan tampilan visual
- JavaScript untuk interaksi halaman
- Git dan GitHub untuk version control serta kolaborasi

## Fitur Utama
- Menampilkan nama utama secara jelas pada bagian pembuka
- Menyediakan pengantar singkat tentang makna nama
- Menampilkan kutipan motivasi
- Navigasi sederhana menuju bagian isi halaman
- Struktur halaman yang ringan dan mudah dikembangkan
