Git basics

Make changes without losing your way.

Branches give your ideas room to grow. Merge brings the finished work back together.

Start the lesson

The simple idea

Think of your main branch as the dependable path through a project. A new branch is a safe side path where you can experiment.

  1. 1. Create a branch

    Give your new idea a name and move onto it.

    git switch -c new-idea

  2. 2. Save your work

    Stage the changes and record them in a commit.

    git add .
git commit -m "Describe the new idea"

  3. 3. Merge it back

    Return to the main branch, then bring in the finished work.

    git switch main
git merge new-idea

See the journey

main     o---o-----------o
							\         /
new-idea       o---o---o

The final commit on main contains the work from new-idea.

Remember

A branch is just a movable label pointing to a commit. Creating one is cheap, so use branches for focused pieces of work.

One small branch at a time.
